Scooby-Doo Legal Watch Catalog

File: scooby_doo_catalog.json

This is a separate reference catalog for Scooby-Doo TV series, with India-focused legal watch-guide links and reported providers where a current listing was found. Availability can change by date, subscription, language, and region; open the linked guide to verify before subscribing.

This file intentionally contains no torrent hashes, magnet links, or unverified torrent-speed claims. Torrent speed cannot be reliably inferred from a release name alone; it depends on live seeders, peer connectivity, and swarm health.

Integration note: the current Mystery Vault app uses the hard-coded CATALOG array in server.js for playable items. This JSON is a standalone reference catalog and will not appear in the app UI unless the server is updated to load it as a separate legal-watch section. It is not a playable-torrent catalog.
