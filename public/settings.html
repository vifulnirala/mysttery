DNS settings

Use AdGuard DNS to block many ad, tracker, and known malicious domains inside Mystery Vault.

Default: AdGuard DNS (94.140.14.14). App-only; Windows network settings are not changed.

Custom entries must be HTTPS DNS-over-HTTPS URLs, not plain IP addresses. DNS filtering blocks many ad domains, but cannot remove every ad embedded in a video stream.
